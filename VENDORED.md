# Source provenance and external rights

No third-party source, datasets, pretrained weights or checkpoints are vendored in
the product repository. Newly authored source is MIT licensed under LICENSE with Roy's
explicit authorization. That license does not cover outside model/data artifacts.

R03 generated `uv.lock` and installed runtime, development and build dependencies
in project-local environments. The selected interpreter is CPython 3.12.13; direct
pins include Pydantic 2.12.3, pytest 8.4.2, Ruff 0.14.2, Hatchling 1.27.0 and
editables 0.5. The lock records exact transitive versions and package artifact
hashes. Windows bootstrap/check and offline wheel execution have independent
validation; native POSIX execution remains unverified. See the root README and
[local validation checkpoint](docs/VALIDATION.md) for scope and reproduction.

Installation and version checks do not constitute a dependency license audit or
legal clearance. Review the exact selected distributions and transitive terms
before any redistribution; the project's MIT license does not replace them.
These local installed dependencies are not vendored third-party source, model
weights or datasets in the product repository.

The selected plan names GLiNER small v2.1 as a candidate, not an approved artifact.
Before download or use, archive exact model, backbone, tokenizer, code and data
revisions/licenses, permitted derivative/distribution terms and hardware feasibility.
Frontier provider/version/terms and capped spend need separate authorization.

Prior-art descriptions informed design; no upstream claims are reproduced as measured
M7 evidence and no upstream source/data was copied. Public raw development fixtures
are original fictional examples, clearly separate from any future sealed test.

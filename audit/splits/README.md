# Split evidence boundary

This directory is reserved for future value-free split-audit receipts. No completed
split audit, signed custody approval or test inventory exists here. Private source,
labels and ancestry inventories belong under custodian access control, outside
public/development artifacts. See `docs/data-custody.md` for source contracts.

Mechanical audit records expose requested/effective block counts, commitments,
reason codes and pending independent/label-audit fields. Never publish test-family
names, gold span tables, lexicons, raw strings or normalized value hashes here.
The development inventory is one shared component, not twenty independent units.
